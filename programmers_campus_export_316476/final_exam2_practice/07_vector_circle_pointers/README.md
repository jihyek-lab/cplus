# 객체지향 프로그래밍 [10-15] 객체 포인터를 vector에 삽입, 삭제

- 학습 주제: vector와 객체 포인터 관리
- 실습 목표: vector<Circle*>를 사용해 객체를 추가, 삭제, 출력하는 문제입니다.

## 구현 체크리스트

- add에서 동적 생성한 Circle 포인터를 push 하기
- remove에서 이름이 일치하는 원을 모두 삭제하기
- show에서 이름과 넓이를 출력하기
- 소멸자에서 메모리 해제를 고려하기

## 실습 힌트

포인터를 erase 하기 전에 delete 해야 메모리 누수를 막을 수 있습니다.

## 원문 문제 설명

circle 클래스가 다음과 같이 구현되어 있을때, CircleVectorManager 클래스를 완성하라.
void add(): radius 와 name을 입력받아서, v 에 마지막에 push 한다.
void remove(): name을 입력받아서, name과 같은 이름을 가지고 있는 circle을 모두 v에서 삭제한다.
void show() : v 에 저장되어있는 모든 원의 이름과 넓이를 출력한다.
힌트
vector v; 형식으로 벡터를 생성한다.
v.erase(it) 는 벡터 v 에서 it 를 가르키는 원소를 삭제하고 난 다음, 벡터 내에 삭제된 다음 지점의 첫 원소에 대한 포인터를 리턴한다. 그러므로 원소를 삭제한 후 다음 원소의 주소를 잡으려면 간단히 다음과 같이 하면 된다.
it = v.erase(it);
입출력 예시
1 : add 를 수행
2 : remove 를 수행
3: show 를 수행
4: 종료
입력 1
1 1 c1
1 2 c2
3
2 c1
3
4
출력 1
c1 3.14
c2 12.56
c2 12.56
